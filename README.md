# 高校专业库

把"这个专业到底学什么、毕业去哪、哪些坑要提前绕"写成能直接查阅的文档。

如果你愿意认领一个专业，把那段经历写成文字交给我们，这个库就从"通用初稿"变成了"有人验证过的答案"。

能给学弟学妹留一点经验，少走一点弯路，你就配享太庙。

学习资料，八卦、升学问题、应试技巧都可以

项目按 **大专 / 本科 / 硕士 / 博士** 四个层次组织，第二层是大类，第三层是具体专业。每个专业目录下固定两份文件：`生存指南.md` 和 `避坑指南.md`。目录与专业名称、代码均取自教育部现行目录，不是二手拼凑。

## 每份文件长什么样

两份文件都以 YAML front matter 开头，字段供协作和 CI 校验使用：

| 字段 | 说明 | 示例 |
|---|---|---|
| 层次 | 大专 / 本科 / 硕士 / 博士 | 本科 |
| 专业代码 | 教育部目录代码，保留 T/K 后缀 | 080202 |
| 学科门类 / 专业大类 | 上级归属 | 工学 |
| 专业类 | 本科的专业类，或专科的专业类 | 机械类 |
| 类别 | 硕博专用：一级学科 / 专业学位类别 | 一级学科 |
| 状态 | 初稿 / 已校订 / 待更新 | 初稿 |
| 维护人 | 认领者的 GitHub ID，未认领为"待认领" | 待认领 |
| 最近更新 | 最后一次实质修改日期 | 2026-11-25 |
| 依据 | 所依据的官方目录 | 普通高等学校本科专业目录（2024年） |

正文部分：《生存指南》写这个专业在做什么、几年怎么过、练什么能力、往哪走、自检清单；《避坑指南》写常见误解、高频坑、选课证书实习的风险点、一句话提醒。

## 现状：骨架已经搭好，血肉还没长出来

现有内容是按学科门类生成的通用初稿，同一门类下几十个专业共用一套说法。它能保证不出硬伤，但做不到"说到点子上"——机械类三十多个专业的课程侧重、行业景气、薪资结构差别很大，一段通用话只能算及格。

真正值钱的信息只有亲历者知道：哪门课劝退、哪个老师值得跟、实习单位是当劳动力还是当学徒、招聘时看不看第一学历、入职三年后什么状态、哪些证书是智商税。这些进不了招生简章，也搜不出来。

所以这个仓库采用 GitHub 的协作方式：**谁经历过，谁来写；谁发现问题，谁来改；一切通过 Issue 和 Pull Request 留下痕迹。**

## 怎么参与

1. **认领**：在 Issues 里选一个专业（或新开一条"认领" Issue），说明你的毕业年份、院校层次、现在做什么。
2. **提交**：Fork 仓库，在自己的分支上只改这个专业目录下的文件，开 Pull Request。PR 会自动跑结构校验。
3. **评审合并**：一位维护者 + 一位同专业贡献者交叉看一遍，确认内容属实、无广告、无隐私后合并。

详细规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 本地校验与重建

```bash
python scripts/validate.py        # 校验目录结构与元信息，CI 也跑这个
python scripts/fetch_pdfs.py      # 下载三份官方目录 PDF 并抽取文本
python scripts/parse_catalog.py   # 解析为 data/catalog.json
python scripts/generate_tree.py   # 重建目录与文件（会覆盖未提交的改动）
```

依赖：Python 3.9+、`pypdf`。
