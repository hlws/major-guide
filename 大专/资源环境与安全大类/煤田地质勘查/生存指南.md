# 煤田地质勘查 · 生存指南

> 层次：专科（高职） ｜ 专业大类：资源环境与安全大类 ｜ 专业类：资源勘查类 ｜ 专业代码：420105 ｜ 学制：一般三年

## 这个专业在做什么

面向测绘、地质、环保与安全生产一线的技术技能岗位。

## 三年节奏

- **第一年**：文化基础课 + 专业入门技能，把工具和规范先摸熟。
- **第二年**：实训、考证、技能竞赛，尽量进实训室和校企合作项目。
- **第三年**：顶岗实习 + 就业或专升本，实习单位要挑能学到东西的。

## 技能重点

- 测量、CAD/GIS 与监测仪器操作
- 地质与环保基础、样品采集
- 安全规程、外业记录与报告编写

## 就业与升学

- 测绘院、地质队与环保公司
- 工矿企业安全员、环保运维
- 应急管理与第三方检测机构

- 专升本：多数省份在大三上学期报名，考试科目以公共课 + 专业课为主，务必查本省当年政策。

## 通用硬通货

- 一本能证明你上手能力的技能证书（与岗位直接相关的那一种）。
- 办公软件 + 基础数据处理能力，任何岗位都加分。
- 一段真实的顶岗实习经历和一份能说清工作内容的简历。
- 安全意识与规范意识：一线岗位最看重这个。

## 自检清单

- [ ] 能独立完成本专业最基础的一项真实工作任务
- [ ] 清楚对口岗位的起薪、班制和晋升路径
- [ ] 已决定：直接就业 / 专升本 / 考编，并开始准备
- [ ] 有一个可咨询的师傅、学长或企业联系人
